# User stories – StudyBuddy

1. Als student wil ik me registreren met mijn naam en e-mailadres, zodat ik StudyBuddy kan gebruiken.
2. Als student wil ik me aanmelden met mijn e-mailadres en wachtwoord, zodat alleen ik toegang heb tot mijn profiel.
3. Als student wil ik een studiegroep oprichten, zodat ik met medestudenten kan samenwerken.
4. Als student wil ik aansluiten bij een studiegroep, zodat ik samen met anderen kan studeren.
5. Als student wil ik vakken toevoegen aan mijn profiel, zodat ik mijn studiewerk per vak kan organiseren.
6. Als student wil ik per vak de taken en de testen zien, zodat ik weet wat ik moet doen.
7. Als student wil ik mijn voortgang van testen en taken zien, zodat ik weet hoever ik sta.
8. Als groepslid wil ik een studiesessie plannen met een datum en locatie, zodat ik samen met andere studenten kan studeren.
9. Als groepslid wil ik aansluiten bij een studiesessie, zodat anderen weten dat ik erbij ben.
10. Als groepslid wil ik samenvattingen en documenten delen bij een studiesessie, zodat wie afwezig was ook kan meevolgen.
